# TFS Android Spring 2024

## Описание

Этот проект был выполнен в рамках курса "Тинькофф Финтех: Android-разработка 2024". 

Это приложение представляет собой чат, основанный на [Zulip API](https://zulip.com/api/). Оно позволяет пользователям общаться в различных каналах и топиках, ставить реакции на сообщения, удалять и редактировать сообщения, а также просматривать информацию о себе и о других пользователях.

Ссылка на скринкаст: https://www.youtube.com/watch?v=jENW9kSaJqM


## Технологии

- XML + Compose View
- MVI (MviKotlin)
- Corouties / Flow
- OkHttp / Retrofit
- Dagger 2
- Cicerone
- Kotest / Kaspresso / Wiremock 
- Clean + Многомодульность

## Выполненные задачи

Были выполнены все основные и дополнительные требования.

Почти вся верстка сделана на Compose (кроме обязательных требований). Compose cписки каналов и пользователей могут лагать (тут ничего поделать не могу :с)

Все данные кешируются, приложением можно пользоваться без доступа к интернету

Реализованы Ui и Unit тесты экрана чата

#### Экран Channels

- Просмотр каналов и топиков
- Создание канала (плюсик справа снизу)
- Поиск канала
- Переход в чат конкретного топика (развернуть канал нажатием на стрелочку, а затем нажать на топик)
- Переход в чат канала (иконка списка, справа от каждого канала)

#### Экран People

- Просмотр всех пользователей чата
- Просмотр статуса каждого пользователя
- Поиск пользователей

#### Экран Profile

- Просмотр своего аккаунта

#### Экран Chat (топик)

- Просмотр сообщений написанных в данный топик
- Возможность написать, отредактировать, удалить сообщение (долгое нажатие на сообщение)
- Возможность ставить реакции (долгое нажатие на сообщение или нажатие на плюсик)

#### Экран Chat (канал)

- Просмотр всех сообщений написанных в данный канал (фильтрация по топикам)
- Возможность написать, отредактировать, удалить сообщение в отдельный топик
- Создать новый топик (если его не было ранее)
- Перейти в чат конкретного топика (нажать на полоску с именем топика)
